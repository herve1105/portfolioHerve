# Portfolio Personnel - Hervé Mazumbu

## Description

Ce projet est un portfolio personnel développé en HTML, CSS et JavaScript. Il présente mon profil, mes compétences, mes services, mes projets, mon parcours, ainsi qu’un formulaire de contact.

L’objectif principal de ce portfolio est de mettre en avant mes compétences en développement web frontend à travers une interface moderne, responsive et professionnelle.

## Fonctionnalités

- Interface moderne inspirée d’un portfolio professionnel
- Design responsive adapté aux mobiles, tablettes et ordinateurs
- Menu de navigation latéral
- Style switcher pour changer la couleur principale
- Mode clair et mode sombre
- Section services
- Section compétences
- Section portfolio avec filtres
- Section CV avec accordéons
- Section témoignages
- Formulaire de contact avec validation JavaScript
- Sauvegarde du thème et de la couleur dans le navigateur

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Git et GitHub
